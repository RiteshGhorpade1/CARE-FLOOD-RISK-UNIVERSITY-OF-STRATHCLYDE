# Archive

Superseded exploratory notebooks and scripts from earlier stages of the CARE
project. They are **not** part of the maintained pipeline described in the
top-level README and are kept only for provenance (e.g. showing how the
39-year rainfall rework evolved before it was folded into
`03_Feature_Engineering.ipynb`).

They are not guaranteed to run as-is: several still use the author's
original absolute filesystem paths and reference intermediate files that
were reorganised or removed during the `002_Dataset/raw`/`processed`/
`outputs` restructuring. Do not treat anything here as the current or
canonical version of the pipeline — see `003_Code/01_Data_Collection.ipynb`
through `04_ML_Model.ipynb` for that.
